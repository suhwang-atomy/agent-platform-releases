# Atomy Office Agent — Releases

Public installers for Atomy Office Agent.

The application source is maintained in a separate private repository. This repository does not contain organizational knowledge, user workspaces, or credentials.

## Downloads

[Download Atomy Office Agent](https://suhwang-atomy.github.io/agent-platform-releases/) or browse the [Releases page](https://github.com/suhwang-atomy/agent-platform-releases/releases).

Windows x64 0.1.2 is being prepared. Previous version: [Download 0.1.0 installer](https://github.com/suhwang-atomy/agent-platform-releases/releases/download/v0.1.0/aoa-windows-setup.exe). The installer is not Windows code-signed, so SmartScreen may display a warning.

macOS Apple Silicon: [Download installer](https://github.com/suhwang-atomy/agent-platform-releases/releases/latest/download/aoa-macos-apple-silicon.dmg). The app is ad-hoc signed and not notarized by Apple; macOS may restrict opening it.

Latest release: 0.1.2 for macOS Apple Silicon. Windows 0.1.2 is pending.

Updates currently use the download page. No automatic-update manifest is published for 0.1.2. Application signing/notarization and update signing are separate checks.
