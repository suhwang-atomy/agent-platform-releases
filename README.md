# Atomy Office Agent — Releases

Public installers for Atomy Office Agent.

The application source is maintained in a separate private repository. This repository does not contain organizational knowledge, user workspaces, or credentials.

## Downloads

[Download Atomy Office Agent](https://suhwang-atomy.github.io/agent-platform-releases/) or browse the [Releases page](https://github.com/suhwang-atomy/agent-platform-releases/releases).

Windows x64: [Download installer](https://github.com/suhwang-atomy/agent-platform-releases/releases/latest/download/aoa-windows-setup.exe). The installer is not Windows code-signed, so SmartScreen may display a warning.

macOS Apple Silicon: [Download installer](https://github.com/suhwang-atomy/agent-platform-releases/releases/latest/download/aoa-macos-apple-silicon.dmg). The reissued 0.1.7 app is Developer ID signed. Apple notarization is pending, so macOS may still block first launch.

Latest release: 0.1.7 for macOS Apple Silicon and Windows x64. The macOS signing reissue preserves the existing version and product functionality; the Windows installer is unchanged.

Automatic updates are available from 0.1.5 onward. Existing 0.1.7 users must reinstall from the new DMG to receive the signing reissue, because the version has not changed. Application signing/notarization and update signing are separate checks.

Contact: suhwang@atomypark.com
