# Atomy Office Agent — Releases

Public installers and signed update manifests for Atomy Office Agent.

The application source is maintained in a separate private repository. This repository does not contain organizational knowledge, user workspaces, or credentials.

## Downloads

The first release has not been published yet. Installers will appear on the [Releases page](https://github.com/suhwang-atomy/agent-platform-releases/releases).

Supported release targets: macOS Apple Silicon, macOS Intel, and Windows x64. Availability depends on successful platform builds and testing.

Updates use a signed `latest.json` manifest and signed platform artifacts. Application signing/notarization and update signing are separate checks.
